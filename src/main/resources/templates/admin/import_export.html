description Tải File Mẫu (sample_products.csv)

info Cấu Trúc Các Cột Trong File CSV

  • 1. ISBN: Mã định danh sách (nếu có, để đối soát sản phẩm trùng).
  • 2. TenSP (*): Tên sách hoặc văn phòng phẩm (Bắt buộc).
  • 3. GiaBan (*): Đơn giá bán (VNĐ, kiểu số nguyên).
  • 4. SoLuongTon (*): Số lượng tồn kho ban đầu (số nguyên).
  • 5. LoaiSP: Sach, VanPhongPham hoặc QuaTang.
  • 6. MaDanhMuc: Mã danh mục (ID số nguyên trong hệ thống).
  • 7. MaNXB: Mã Nhà xuất bản liên kết.
  • 8. MoTa: Tóm tắt giới thiệu nội dung cuốn sách.
💡 Mẹo: Hãy mở file mẫu bằng Excel, nhập liệu và chọn Save As → CSV UTF-8 (Comma delimited) (*.csv) để giữ đúng nguyên vẹn dấu tiếng Việt.
